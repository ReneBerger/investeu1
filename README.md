# InvestEU Immobilienwebsite

Dynamic static website for a real estate agent. The site is designed to look and feel similar to immo17.at while loading current real estate listings from an OpenImmo XML export generated by Immoz.

## Zielarchitektur

```text
index.html                 Static page shell, search/list/detail containers
styles.css                 Visual design and responsive layout
script.js                  UI orchestration: load, filter, render list/detail
src/openimmo.js            OpenImmo XML loading and normalization
src/contentTransforms.js   Text/content modification and translation hooks
data/openimmo.xml          Current OpenImmo feed generated by Immoz
netlify.toml               Netlify deployment configuration
```

## Datenfluss

1. Immoz generates a regularly updated OpenImmo XML file.
2. The newest XML file is published to `data/openimmo.xml` during deployment or by a later automation step.
3. The browser loads the XML with `fetch(..., { cache: 'no-store' })`, so replaced XML content becomes visible without changing the application code.
4. `src/openimmo.js` parses each `<immobilie>` and normalizes it into the internal property format used by the list view, filters and detail view.
5. `src/contentTransforms.js` applies text replacements/translations before content is displayed. The exact rules can be extended later when the final modification requirements are known.
6. Objects no longer present in the XML disappear automatically because the rendered state is rebuilt from the current XML file on each load.

## OpenImmo / Immoz feed

The project uses OpenImmo as the exchange standard for real estate data:

- Standard/download: <https://www.openimmo.de/go.php/p/24/download.htm>
- XML source system: <https://immoz.immoz.net/>

For local development, replace `data/openimmo.xml` with an Immoz export that follows the OpenImmo structure. The committed file is only a small sample feed for development and layout testing.

## Local development

Because browsers block `fetch()` for local files, run a small local server instead of opening `index.html` directly:

```bash
python3 -m http.server 8080
```

Then open <http://localhost:8080/>.

## Deployment on Netlify

The site is deployed as static files. Netlify can publish the repository root (`.`). Future automation can update `data/openimmo.xml` before deployment, for example by downloading the latest Immoz export in a scheduled workflow.
